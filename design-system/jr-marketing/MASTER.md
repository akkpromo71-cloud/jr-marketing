## Global Rules

### Color Palette — dark only, OLED night

Base is a blue-black, not neutral slate. **These are the real values shipped in
`src/app/globals.css` — that file is the source of truth, not this document; if
they ever disagree again, fix this file, not the CSS.**

Since the clipping-platform pivot, colour is **functional, not role-based** —
pink no longer means "client" and blue no longer means "clipper" (see Tool mode
below for the full legend). Pink now appears only on the showcase (landing,
logo, brand marks); the tool mode uses blue/green/yellow/red purely by meaning.

| Role | Hex | CSS Variable | Notes |
|------|-----|--------------|-------|
| Background (page) | `#0B0F1A` | `--bg` | near-black, blue-tinted; the "night" |
| Surface (raised) | `#111725` | `--surface` | sections lifted off bg, ticker base is pure `#000` |
| Field / chip fill | `#1A2333` | `--surface-2` | inputs, skeletons, tags |
| Foreground (body) | `#F4F5F7` | `--text` | body copy; **not** pure white (OLED bloom) |
| Foreground (dim) | `#C7CDD9` | `--text-dim` | secondary text — 12:1 on bg |
| Foreground (faint) | `#98A2B3` | `--text-faint` | labels, meta, captions — 5.9:1 on bg |
| Border / hairline | `rgba(255,255,255,0.10)` | `--border` | 1px rules replace cards on the landing |
| **Brand accent — showcase/logo only** | `#EC4899` | `--primary` | pink; landing hero, logo — not used in tool mode |
| On Primary | `#0A0A0A` | `--on-primary` | black text on pink fill = 6.2:1 ✓ (white = 3.3 ✗) |
| **Accent — action / links / main CTA** | `#3B82F6` | `--accent` | blue; the one functional "do something" colour, both modes |
| On Accent | `#0A0F1C` | `--on-accent` | near-black on blue fill = 6:1 ✓ |
| **Success — confirmed / paid / credited** | `#34D399` | `--success` | approved work, paid withdrawal, active campaign |
| **Warning — pending / under review / held** | `#F5B841` | `--warning` | pending moderation, paused, antifraud hold |
| **Danger — rejected / removed / denied** | `#FB7185` | `--danger` | rejected work, post removed, expired |
| Ring (focus) | `#3B82F6` | via `--accent` | 2px solid + 2px offset, never removed |

**Contrast, verified on `#0B0F1A`:** `#F4F5F7` 17.6:1 · `#98A2B3` 5.9:1 · `#34D399` ≥4.5:1 ·
`#EC4899` 5.2:1 (large/UI only) · `#3B82F6` 5.0:1 (text-safe, unlike the old `#2563EB`).

### Gradients — one allowed, and it is not chromatic

- ✅ **Night vignette / spotlight only:** a single static radial behind the hero,
  `radial-gradient(120% 80% at 70% 0%, rgba(37,99,235,0.06), transparent 60%)`. No motion.
- ❌ No magenta→purple, magenta→blue, or blue→cyan blends anywhere. No blurred gradient
  "blobs". Accents appear as **solid fills, 1px borders, or one tight glow** (see Effects).

### Typography — Unbounded + Manrope + JetBrains Mono (all Cyrillic-verified)

| Font | Role | Cyrillic subset | Why |
|------|------|-----------------|-----|
| **Unbounded** | display / H1–H2 / section kickers, weights 600–800 | ✅ `cyrillic` (Google Fonts) | loud, kinetic, "club poster / label drop" energy without a script/AI look |
| **Manrope** | body, UI, buttons, labels, weights 400–800 | ✅ `cyrillic`, `cyrillic-ext` | calm, semi-geometric, modern, reads as *trustworthy* — the counterweight to Unbounded |
| **JetBrains Mono** | stats, the "Лента" ticker, slot numbers, weights 400–500 | ✅ `cyrillic`, `cyrillic-ext` | tabular figures for the real-numbers story; monospace = "receipt / ledger" honesty |

```css
@import url('https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&family=Unbounded:wght@400;600;700;800&family=JetBrains+Mono:wght@400;500&display=swap');
```
```
--font-display: 'Unbounded', 'Manrope', ui-sans-serif, system-ui, sans-serif;
--font-sans:    'Manrope', ui-sans-serif, system-ui, sans-serif;
--font-mono:    'JetBrains Mono', ui-monospace, 'SFMono-Regular', monospace;
```

**Type scale** — reuse the existing scale already in `tailwind.config.ts` (do not invent a
second one). Contrast between `display` and `meta` is ~10× on purpose.

| Class | Size | Family | Where |
|---|---|---|---|
| `text-display` | `clamp(2.75rem, 1rem + 7vw, 6rem)` / lh 0.95 / -0.035em | Unbounded 700–800 | hero H1, the one hero stat, final CTA line |
| `text-display-sm` | `clamp(2.1rem, 1.2rem + 4vw, 3.75rem)` | Unbounded 700 | "Пока идёт первый набор" number, fork panel titles |
| `text-headline` | `clamp(1.6rem, 1.1rem + 2.4vw, 2.5rem)` | Unbounded 600 / Manrope 800 | section headings, FAQ heading |
| `text-title` | `1.25rem` / -0.01em | Manrope 700 | card titles, FAQ question |
| `text-body-lg` | `1.0625rem` / lh 1.6 | Manrope 400–500 | lead paragraph, FAQ answer |
| `text-body` | `1rem` / lh 1.65 / measure ≤ 42rem | Manrope 400 | paragraphs |
| `text-meta` | `0.75rem` / uppercase / 0.14em | Manrope 600 | kickers, labels, metadata |
| `text-micro` | `0.6875rem` / 0.06em | JetBrains Mono 400 | roster annotations ("эдитов: 1") |
| stat figures | inherits size | **JetBrains Mono + `tabular-nums`** | every number on the page |

Body ≥ 16px. Line-height 1.5–1.65 for prose. Never set Unbounded below `text-title` size — it
is a display face only.

### Spacing & rhythm

| Token | Value | Usage |
|-------|-------|-------|
| `--space-xs` | `0.25rem` | tight gaps |
| `--space-sm` | `0.5rem` | icon gaps, inline |
| `--space-md` | `1rem` | standard padding |
| `--space-lg` | `1.5rem` | card padding, grid gutter (`--space-gutter`) |
| `--space-xl` | `2rem` | large gaps |
| `--space-2xl` | `3rem` | sub-section margins |
| `--space-section` | `clamp(4rem, 2rem + 9vw, 9rem)` | between major landing blocks |
| `--container` | `72rem` | main content width |
| `--container-text` | `42rem` | prose measure |

### Elevation

**No box-shadow on the landing.** Separation = 1px hairline (`--color-border`) + `--space-section`
whitespace + surface-colour step (`bg` → `surface` → `card`). Shadows allowed only in true
overlays (modal, dropdown, toast): `--shadow-lg: 0 16px 40px -12px rgba(0,0,0,0.6)`.

### Radii — binary (keep the existing convention)

- Buttons, tags, pills, ticker chips → **full pill** (`border-radius: 999px`).
- Cards, inputs, panels, accordion → **`4px`** (near-sharp; `0` also acceptable for full-bleed).
- Nothing in between.

## Component Specs

### Buttons

```css
/* Primary CTA — editor-blue, the single dominant action per view */
.btn-primary{
  background: var(--color-accent); color: var(--color-on-accent);
  font: 600 1rem/1 'Manrope', sans-serif;
  padding: 0.875rem 1.5rem; border-radius: 999px; border: 0;
  cursor: pointer; transition: filter .15s ease, transform .15s ease;
}
.btn-primary:hover{ filter: brightness(1.08); transform: translateY(-1px); }
.btn-primary:active{ transform: translateY(0); }
.btn-primary:focus-visible{ outline: 2px solid var(--color-ring); outline-offset: 2px; }

/* Artist CTA — magenta, used on the artist side of the fork */
.btn-artist{ background: var(--color-primary); color: var(--color-on-primary); /* …same box… */ }

/* Ghost / secondary — hairline pill, for the non-dominant path */
.btn-ghost{
  background: transparent; color: var(--color-foreground);
  border: 1px solid var(--color-border); border-radius: 999px;
  padding: 0.875rem 1.5rem; cursor: pointer; transition: border-color .15s ease, background .15s ease;
}
.btn-ghost:hover{ border-color: rgba(255,255,255,0.24); background: rgba(255,255,255,0.03); }
```
Min hit area 44×44px. ≥ 8px between adjacent targets. Every button shows a loading state on
async submit (label → spinner + "Отправляем…"), never a dead 0ms click.

### Cards / panels

```css
.panel{
  background: var(--color-card); border: 1px solid var(--color-border);
  border-radius: 4px; padding: var(--space-lg);
  transition: border-color .15s ease;
}
.panel:hover{ border-color: rgba(255,255,255,0.18); } /* no transform, no layout shift */
```

### Inputs

```css
.input{
  background: var(--color-muted); color: var(--color-foreground);
  border: 1px solid var(--color-border); border-radius: 4px;

  outline: none; border-color: var(--color-ring);

```
Labels are always visible above the field — never placeholder-only. Errors sit inline under
the field, in `--color-destructive`, with text (not colour alone).

### Modal / overlay (dark — corrected from the generated light default)

```css

  background: var(--color-card); color: var(--color-foreground);
```

### Accordion (FAQ)

Expand via `grid-template-rows: 0fr → 1fr` (or `max-height`), 200ms `cubic-bezier(0.19,1,0.22,1)`.
Chevron rotates 180°. Trigger is a real `<button>` with `aria-expanded`. Under
`prefers-reduced-motion: reduce` → instant open, no rotation tween.

## Style Guidelines

**Style:** Dark Mode (OLED) · **Pattern:** Hero-Centric (one dominant CTA per viewport)

**Key effects (sparingly):**

1. **Night vignette** — one static radial spotlight behind the hero (spec in Gradients). No parallax.
2. **Hairline rules** — `1px var(--color-border)` full-bleed lines between sections; the landing
   has almost no rectangular cards.
3. **"Лента" ticker** — full-bleed black band under the hero, JetBrains Mono, `tabular-nums`,
   real platform numbers scrolling left. `animation-play-state: paused` on hover/focus.
   `prefers-reduced-motion` → show first 3 items, no scroll. No data yet → don't render.
4. **One focal glow — used exactly once** — on the "первый набор" headline number:
   `text-shadow: 0 0 24px rgba(236,72,153,0.35)`. Nowhere else.
5. **Fork hover** — panel border brightens (`.15s`), a thin top rule in the side's colour
   (magenta / blue) grows from 1px to 2px. No scale, no shadow.
6. **Reveal on scroll** — fade + 12px rise, 1 stagger step, `cubic-bezier(0.19,1,0.22,1)`,
   `~450ms`. Disabled under reduced-motion. (Reuse existing `Reveal` / `CountUp`.)

Motion curve everywhere: `cubic-bezier(0.19, 1, 0.22, 1)`. Enter ~450ms, exit ~250ms
(exit faster than enter). One duration per *purpose*, not one duration for everything.

## Tool mode — clipper cabinet, client cabinet, admin

Everything below this section applies **only** to `/feed`, `/applications`,
`/dashboard`, `/admin` and their sub-routes — the working screens where people
look at money and statuses. The Landing Page section further down still
describes the showcase (`/`) exactly as built; tool mode does not touch it.

**Why a second mode at all:** the showcase sells the platform once, at rest.
The tool screens are opened dozens of times a day by someone checking a
balance or a queue — density and scannability beat atmosphere there.

### Rules

1. **Density is roughly half the showcase's.** Where a landing section uses
   `py-section` (`clamp(2.5rem, 1.5rem + 3.2vw, 5.5rem)`), a tool page uses
   `py-6`/`py-8`. Section-to-section gaps use `mt-6`, not `mt-10`.
2. **No Unbounded, anywhere.** Tool-mode headings use Manrope at `text-title`
   size or smaller (`.text-headline`/`.text-display*` force Unbounded — don't
   reach for them here). A page's own `<h1>` is a small uppercase label
   (`text-sm font-semibold uppercase tracking-wide text-text-faint`), not a
   display headline — the number next to it is the real headline.
3. **Every number is JetBrains Mono with tabular figures** — Tailwind's
   `font-mono` utility now resolves to `--font-mono` (JetBrains Mono, added in
   the clipping-platform pivot; previously `font-mono` silently pointed at
   Manrope because the face was never wired up despite being documented
   above). Pair it with `tabular-nums`. Prose and labels stay in Manrope.
4. **Lists are tables (`<table class="tool-table">`, `src/components/tool-ui.tsx`
   `ToolTable`), not card stacks.** A row of a table scans; a stack of cards
   with big titles doesn't, at the density this mode needs. `Card` from
   `src/components/ui.tsx` remains fine for one-off panels (a form, a single
   settings block) — the ban is specifically on turning a *list* of things
   into a *list of cards*.
5. **Colour is functional, never role-based** (see palette above): green =
   confirmed/paid/credited, yellow = pending/under review/held, red =
   rejected/removed/denied, blue = action/link. Pink is off-limits in tool
   mode entirely — it's the showcase's brand colour, not a "client" colour.
   Concretely: use `variant="primary"` (blue) for the client's primary actions
   too, never `variant="artist"` (pink), inside tool-mode screens.
6. **One dominant number per screen** (`ToolStat` in `tool-ui.tsx`) — the
   clipper's balance, the client's delivered views. Every other figure on the
   screen is visibly smaller (`ToolFigure`, or a plain table cell).
7. **No entrance animation.** Skip `.pop-in`, `HeroReveal`, scroll-reveal —
   those exist for the showcase's one-time sales pitch and read as noise on a
   screen someone opens ten times a day. Ordinary hover/focus feedback on
   buttons and links is unaffected — this rule is about pages/sections
   animating *in*, not about interactive affordances disappearing.

### Reference screen

`/applications` ("Мои работы" — the clipper's wallet + slots + submissions +
history) is the exemplar this section describes; it was built first and shown
to the client (a static preview, since the real page sits behind auth) before
the same conventions rolled out to the rest of tool mode. Match it rather than
re-deriving the rules per screen.

### Responsive — required breakpoints

`375` · `768` · `1024` · `1440`. Mobile-first. No horizontal scroll at any width
(`overflow-x: clip` on full-bleed sections). `<meta name="viewport" content="width=device-width, initial-scale=1">`,
never `maximum-scale`/`user-scalable=no`. Hero split → stacked < 768. Fork → stacked, equal < 768.
Ticker keeps scrolling on mobile but respects reduced-motion.

## Anti-Patterns (Do NOT Use)

From the brief — hard bans:

- ❌ **Violet / pink "AI" gradients** — no magenta→purple, magenta→blue, blue→cyan blends;
  no blurred gradient blobs. (See Gradients: only the flat night vignette is allowed.)
- ❌ **Emoji as icons** — SVG only, from **Lucide** or **Phosphor**, one set per surface.
- ❌ **Stock "team behind laptops"** / generic office photography.
- ❌ **Carousels / sliders** — lay content out; let it scroll the page.
- ❌ **Invented numbers or case studies** — the real figures are `1` / `6` / `166,6K`.
  Present them with weight and honesty; never round up, never imply a queue.

From the generated system + OLED style:

- ❌ Pure-white (`#FFFFFF`) page backgrounds or large blocks.
- ❌ Pure-white body text at large sizes (bloom on OLED) — use `#F4F5F7`; white only for `text-display`.
- ❌ Box-shadow for separation on the landing — use hairlines + whitespace.
- ❌ Icon-in-circle + heading + paragraph repeated as a "features" row (kills the ledger tone).
- ❌ Layout-shifting hovers (scale transforms that reflow); instant 0ms state changes.
- ❌ Removing / hiding focus rings; hover-only affordances with no tap/focus equivalent.
- ❌ Unbounded used below `text-title` size, or for running text.

Tool mode only (see the section above):

- ❌ Unbounded anywhere in a cabinet/admin screen — Manrope only.
- ❌ A number set in the body font instead of `font-mono tabular-nums`.
- ❌ A *list* of things rendered as a stack of cards instead of `ToolTable` rows.
- ❌ `variant="artist"` (pink) on a client-side action — pink is showcase/brand
  only now; use `variant="primary"` (blue) for the client's primary actions too.
- ❌ Entrance/reveal animation on a tool-mode page or section.
- ❌ Landing-scale section spacing (`py-section`, `mt-10` between sections) —
  use the halved density instead.

## Pre-Delivery Checklist

- [ ] Fonts load with `cyrillic` subset; RU text renders in Unbounded / Manrope / JetBrains Mono, no fallback tofu
- [ ] No emoji icons; all icons from Lucide **or** Phosphor, one set per surface
- [ ] No chromatic gradients; only the flat night vignette behind the hero
- [ ] Text contrast ≥ 4.5:1 (body) / ≥ 3:1 (large & UI) — spot-check magenta and blue on `#0B0F1A`
- [ ] `cursor: pointer` on every clickable; hover transitions 150–300ms
- [ ] Focus visible (`2px` ring + `2px` offset) on all interactive elements, keyboard-reachable
- [ ] `prefers-reduced-motion`: ticker static (3 items), no reveal tweens, accordion instant
- [ ] Responsive verified at 375 / 768 / 1024 / 1440; no horizontal scroll; zoom not disabled
- [ ] Real numbers only: `1` эдит, `6` эдиторов, `166,6K` просмотров — no rounding, no fake queue
- [ ] Fork panels are equal weight at every breakpoint
- [ ] FAQ is a full section with real answers, not small print in the footer
- [ ] Async buttons show a loading state; forms have visible labels + inline errors
- [ ] Nothing hidden behind the sticky nav (scroll-margin-top on anchor targets)
